# Proyecto Juego - Fundamentos de Programación CESUN

Este es un juego de consola desarrollado en Java donde el usuario debe adivinar un número aleatorio del 1 al 10.

## Estructura del Proyecto
- `Principal.java`: Contiene el método `main` e inicia la ejecución.
- `Funciones.java`: Contiene la lógica del juego y validación de intentos.

## Instrucciones de Ejecución
1. Compilar el proyecto:
   `javac Principal.java Funciones.java`
2. Ejecutar el programa:
   `java Principal`
